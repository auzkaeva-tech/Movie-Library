## Описание проекта
Movie Library - это графическое приложение для управления личной коллекцией фильмов. Программа позволяет добавлять, редактировать, удалять и фильтровать фильмы с сохранением данных в JSON файл.

## Функциональные возможности
-Добавление новых фильмов с указанием названия, жанра, года выпуска и рейтинга
-Редактирование существующих фильмов
-Удаление фильмов из коллекции
-Фильтрация по жанру и году выпуска
-Автоматическое сохранение данных в JSON файл
-Валидация вводимых данных (год от 1888 до текущего+1, рейтинг от 0 до 10)
-Интуитивно понятный графический интерфейс

## Технологии
- **Python 3.8+**
- **Tkinter** - для создания графического интерфейса
- **JSON** - для хранения данных
- **Unittest** - для тестирования
